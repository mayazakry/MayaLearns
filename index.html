Job Description — Senior Solution Architect, Data & AI (Sonata Software) ▸
Sonata Software Permanent · 100% Remote Malaysia or Singapore Fluent Bahasa Melayu/Malay required

🎯 More than just a Solution Architect role

This role goes beyond preparing architecture diagrams. You'll work directly with customers' IT and business leaders to understand their application, data and AI priorities, before translating those requirements into secure, scalable Azure solutions.

You'll lead technical engagements covering solution architecture, Proofs of Concept (POCs) and Minimum Viable Products (MVPs), helping customers evaluate and adopt Azure Data, AI, application and integration technologies.

The role is suitable for an Azure architect who has strong database and data-platform expertise, combined with practical exposure to AI, machine learning, Azure OpenAI or generative AI solutions.

🏢 Sonata Software — Global Technology & Modernization Engineering Company

Sonata Software is a global technology company focused on modernization engineering, cloud, data, Microsoft Dynamics, managed services, automation, cybersecurity and digital transformation.

The company has an established presence within the Microsoft ecosystem and supports enterprise customers across multiple regions and industries.

For candidates who want to deepen their expertise across Microsoft Azure, enterprise data platforms and applied AI, this position offers exposure to customer-facing architecture, solution design, technical workshops, POCs and modern cloud environments.

📈 A Role Built Around Azure Data, AI & Solution Architecture

In this role, you'll be responsible for:

  • Engaging customer IT and business stakeholders to understand their application, database, data and AI priorities
  • Designing secure, scalable and business-focused solutions using Microsoft Azure technologies
  • Leading architecture discussions, technical workshops and solution-design sessions
  • Developing and guiding POCs and MVPs to demonstrate solution feasibility and business value
  • Supporting the adoption of Azure AI, Azure data platforms, application services and GitHub technologies
  • Translating business requirements into practical technical architecture and implementation roadmaps
  • Working with engineering and delivery teams to ensure proposed solutions can be implemented effectively
  • Presenting technical recommendations clearly to both technical and non-technical stakeholders
  • Advising customers on architecture, integration, security, scalability and deployment considerations

🧠 Core Technical Focus

The primary requirement is strong experience in Azure databases and data platforms, supported by practical AI capabilities.

Deep technical capability is expected across:

  • Azure SQL and SQL Server
  • Microsoft Fabric and OneLake
  • Power BI
  • Azure Data Factory
  • Azure Databricks

Strong working knowledge should include:

  • Azure Machine Learning
  • Azure OpenAI
  • Azure Cosmos DB
  • AI and machine-learning solution architecture

Additional exposure may include:

  • PostgreSQL and Azure Database for PostgreSQL
  • Azure Synapse Analytics
  • AI agent development
  • Microsoft Copilot technologies
  • Microsoft Purview and data security

🔧 Relevant Supporting Technologies

Experience in one or more of the following areas would be valuable:

  • Azure AI: Azure AI Foundry, model deployment, Agent Service, Semantic Kernel, Azure AI Search, Azure Machine Learning and SDKs
  • Copilot: Microsoft Copilot Studio and enterprise Copilot solutions
  • Applications and Containers: Azure App Service, AKS, Azure Container Apps, Azure Red Hat OpenShift and Azure Functions
  • Integration: Azure API Management and Azure Logic Apps
  • DevOps: CI/CD, Azure DevOps and DevSecOps practices
  • GitHub: GitHub Copilot, GitHub Enterprise, Advanced Security, Actions and Codespaces
  • AI Infrastructure: Third-party GPU infrastructure and bring-your-own AI model environments
  • Data Platforms: Cosmos DB, Azure SQL, PostgreSQL, Microsoft Fabric and Databricks

Candidates are not expected to be equally specialised in every technology listed. However, strong Azure Data expertise and the ability to connect data platforms with AI use cases are essential.

🪜 What You'll Be Gaining

  • Exposure to enterprise-level Azure Data and AI transformation projects
  • Hands-on involvement in architecture design, POCs and MVPs
  • Opportunities to work directly with customer IT and business decision-makers
  • Deeper experience across Azure SQL, Fabric, Databricks, Azure OpenAI and AI solution architecture
  • Practical exposure to AI agents, cloud-native applications and enterprise integration
  • Experience translating business challenges into commercially relevant technical solutions
  • Broader exposure across Microsoft Azure, GitHub, DevOps and data-security technologies
  • A pathway towards senior cloud, data and AI architecture or technical consulting positions
